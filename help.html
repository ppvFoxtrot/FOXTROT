Welcome

Welcome to the PPV FOXTROT Site Catalog. This page provides a brief guide on navigating and using the website.

Navigating the Site

The homepage contains the Site Catalog, which organizes all available content into expandable categories.

  • Projects – Browse engineering projects by field or chronological order.
  • Software & AI – View software applications, Python utilities, and artificial intelligence projects.
  • Other – Access miscellaneous information, updates, and development logs.

Using Expandable Sections

Many parts of the website use expandable menus. Click on the arrow beside a category to reveal its contents. Click again to collapse it.

Project Pages

Each project may contain descriptions, specifications, research notes, development progress, images, or future plans. Some projects may still be under development and therefore contain limited information.

Website Status

PPV FOXTROT is continuously evolving. New pages, projects, and improvements will be added over time.

Reporting Problems

If you discover broken links, incorrect information, or technical issues, please report them using the contact email provided on the website.
