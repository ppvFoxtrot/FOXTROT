Dual App Launcher

The Dual App Launcher is a lightweight desktop automation script designed to streamline the simultaneous opening and arrangement of two frequently used applications. Built with Python, it leverages system commands and window management libraries to launch the ChatGPT desktop app and Mozilla Firefox, then automatically positions them side by side for efficient multitasking.

Upon execution, the script opens ChatGPT via the Microsoft Store app pathway and starts Firefox. After a brief delay to allow both windows to fully load, it detects the active windows by title, restores them if minimized, and resizes each to half the screen width. Firefox is placed on the left half of the display while ChatGPT occupies the right half, creating a clean, dual-pane workspace without manual adjustment.

Ideal for users who regularly switch between browsing and AI-assisted work, the Dual App Launcher offers a quick, repeatable way to set up a productive dual-window layout. Its simple structure makes it easy to customize paths, timing, or window sizes to match different screen resolutions and personal workflows.

You may copy, paste, edit, and freely use this code for personal and academic purposes on your device.

Importations needed:

For this script to work, you need to have python 3 and the following Python packages installed:

  • pygetwindow press windows + x, select Terminal, write pip install pygetwindow.
  • Once intalled you can use it in your Python scripts.
Python Code (v1) 
import subprocess
import time
import pygetwindow as gw
import os

# Open ChatGPT (Microsoft Store app)
os.system('start shell:AppsFolder\\OpenAI.ChatGPT-Desktop_2p2nqsd0c76g0!ChatGPT')

# Open Firefox
subprocess.Popen(r"C:\Program Files\Mozilla Firefox\firefox.exe")

# Wait for windows to load
time.sleep(8)

firefox_window = None
chatgpt_window = None

for window in gw.getAllWindows():
    title = window.title.lower()

    if "firefox" in title:
        firefox_window = window

    if "chatgpt" in title:
        chatgpt_window = window

# Firefox LEFT
if firefox_window:
    firefox_window.restore()
    firefox_window.moveTo(0, 0)
    firefox_window.resizeTo(960, 1080)

# ChatGPT RIGHT
if chatgpt_window:
    chatgpt_window.restore()
    chatgpt_window.moveTo(960, 0)
    chatgpt_window.resizeTo(960, 1080)

print("Firefox left, ChatGPT right.")
